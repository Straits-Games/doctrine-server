# Security policy

## Reporting a vulnerability

Please report security problems in this server's code privately by email to
**info@straitsgames.com** rather than in a public issue. Include the version
(`doctrine-server version`), what you found and how to reproduce it. We will
acknowledge the report and coordinate a fix and disclosure with you.

## Scope

This repository is the server software only. Straits Games does not run, monitor or
support any Doctrine server: problems with a particular server (its data, its
moderation, its availability) are for whoever runs it. Operator hardening advice is in
[docs/OPERATING.md](docs/OPERATING.md#security-notes).

## Supported versions

Fixes go into the latest release. Operators should keep their servers up to date.
